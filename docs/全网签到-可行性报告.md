## 五、已知限制

1. **Vidu 风控**：无头浏览器必被人机验证拦截——已用可见窗口方案绕过（每天弹窗约 30 秒）
2. **App-only 平台**：腾讯元宝、豆包移动端的签到无法自动化
3. **中转站类**：Any Router / AgentRouter 在本机网络不可达
4. **7 个平台待首次登录**：MiniMax / 通义万相 / 扣子 / 即梦 / 哩布哩布 / 吐司 / PixVerse 需各点一次「登录」授权
5. **百度 Comate**：领取入口可能在 IDE 插件里，网页端仅验证登录态
